## Homebrew Mirrors

Mirrors for some apps that is not available on official Homebrew Taps.

## How to use.

Before using my Homebrew tap, you need to `trust` the repository first.

```bash
brew trust junian/homebrew-mirrors
```

After the system trusted the repository, the next thing to do is to `tap` it.

```bash
brew tap junian/homebrew-mirrors
```

Select the app you need and install using command line like this:

```bash
brew install <formula>
brew install --cask <formula>
```

## Available Formulae

### Microsoft Office for Mac

```bash
brew install microsoft-office-for-mac
```

Compatible with following macOS versions:

- macOS 13 (Ventura)
- macOS 12 (Monterey)
- macOS 11 (Big Sur)
- macOS 10.15 (Catalina)

- macOS 10.13 (High Sierra)
- macOS 10.12 (Sierra)
